Terminal v2 — 3 design directions

Concept locked: a terminal window showing repo info as CLI output. Refreshing execution within the unified family. Light + dark variants shown for each.

Direction A — Crisp IDE recommended

A modern terminal with macOS-style chrome, soft pastel prompt, GitHub-style muted blue accent, and clean key-value output. Reads as "developer tool" rather than "retro computer".

Type & spacing

  • JetBrains Mono, 800 for repo title (36px), 500 for body (18px), 500 for stats (17px)
  • Soft 8px line height on body lines, generous 32px between sections
  • Dotted divider separates metadata from output

Palette (dark / light)

  • bg
  • accent (link / repo)
  • prompt (purple)
  • language dot
  • subtext (key labels)

Direction B — Old Terminal (CRT)

Phosphor-green CRT with scanlines, subtle text glow, vignette, and a "last login" header. Vintage and atmospheric — leans into the retro computer reading of the concept.

Type & spacing

  • JetBrains Mono only, glow filter on text in dark mode
  • Heavier 800 weight on title (38px), 16–17px body, `[x]` symbol prefixes for stats
  • Scanline pattern overlay (1.5px stride, 0.15 opacity) for CRT effect in dark
  • Vignette gradient at edges to imply CRT curvature

Palette (dark / light)

  • bg (phosphor black / paper white)
  • phosphor / ink
  • output text (soft green / charcoal)
  • border

Direction C — Modern CLI (Starship)

No window chrome — just a clean rounded panel with a subtle gradient backdrop, a single horizontal stat row, and a starship/prompt-style header pill. Minimal, refined, contemporary.

Type & spacing

  • JetBrains Mono throughout; 800 weight on title (44px)
  • Single horizontal stat row at bottom with `·` separators — most info-dense layout of the three
  • Header pill with avatar + repo path
  • No window chrome — relies on panel + border for containment

Palette (dark / light)

  • bg (subtle diagonal gradient)
  • panel
  • accent (link)
  • divider / separator
  • language dot
